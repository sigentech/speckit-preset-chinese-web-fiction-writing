# 网文黄金三章（开篇工程）

数据现实：过半弃书发生在第一章 1/3 处之前；读完第三章的读者约为点开时的 20%。开篇的唯一任务是**让读者点开第四章**。

## 总原则：简单 + 有趣

做到「简单」的三刀：
1. **砍无关内容**：每段都问「删了它故事还成立吗」，成立就删。
2. **砍特殊信息量**：人名、地名、功法名都是读者的记忆成本。前三章出场人物越少越好，非必要不出场。
3. **后置必要的无聊内容**：背景、设定、主角前史，能挪到三章之后边讲边交代的，一律后置。

## 三章任务分解

| 章节 | 任务 | 操作要求 |
|---|---|---|
| 第 1 章 | 勾住 | 前 300 字内出钩（悬念/冲突/金手指三选一）；主角前半章出场，亮明身份与当下困境；章末留钩 |
| 第 2 章 | 加深 | 确立核心矛盾，读者知道「这本书讲什么」；展示金手指用法；引出长期冲突 |
| 第 3 章 | 锁定 | 第一个小高潮，亮明爽点类型；铺垫不超过 500 字 |

附加：打斗/升级文前五章内亮出力量体系；每章章末留钩。

## 开篇五法（可直接套用）

1. **不通的画面**：抛出说不通的事，先不解释（解释是悬念的天敌）。
2. **反差**：身份与行为错位，反差越大越好（乞丐讲金融、圣子去摆摊）。
3. **第一句就进冲突**：干架、退婚、处死、分手、被抓，跳过铺垫。
4. **平静地说荒诞**：用习以为常的语气亮出世界观（「灵根分期付款」）。
5. **血压开局**：写不公而非卖惨，付出与回报落差越大，读者越想主角赢。

核心一个字：**打破**（打破日常、预期、平衡）。

## 禁忌清单（新人高频死因）

- 写序章/楔子——直接上正文第一章
- 第一人称「我」——用主角名字，第三人称
- 大段环境描写、背景介绍、抒情开头
- 前三章抛出大量设定、人名、势力关系
- 慢悠悠的日常开局（「先熟悉世界」= 让读者离开）
- 主角第三章还没出场或没有欲望目标

## 十条自检表（写完/审稿时逐条打勾）

- [ ] 前 300 字有钩子（悬念/冲突/金手指）
- [ ] 第一章前 1/3 处主角已出场，有名字、有身份
- [ ] 三章内主角有明确短期目标 + 长期冲突
- [ ] 出场人物 ≤ 5 个，每个都有戏份必要性
- [ ] 专有名词 ≤ 5 个
- [ ] 金手指（若有）已亮相并展示过一次用法
- [ ] 每章章末有钩子
- [ ] 第三章出现了一个小爽点
- [ ] 通篇无大段背景/环境/前史介绍
- [ ] 删掉任何一段，故事都会受影响（否则该段是废话）
