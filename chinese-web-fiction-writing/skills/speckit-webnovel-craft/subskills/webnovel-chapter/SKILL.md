# 网文章节微操（文笔与单章结构）

## 单章内部结构（2000–3000 字/章）

```text
开头（≤200 字）：快速进入状态，承接上章钩子，不寒暄
中段：推进 1 个核心事件（一章只讲一件事，干干净净）
收尾：停在悬念/反转/危机将爆处
```

## 章末钩子

常用类型：新危机降临 / 反转前一刻 / 身份将揭未揭 / 强者登场 / 主角做出反常决定 / 获得关键信息但来不及行动。

停在「见到敌人之后」而非「见到敌人之前」——前者留悬念，后者给读者「可以休息」的信号，休息就忘了。

每章写完自查：**这一章停在这儿，我自己想不想点下一章？**

## 可读性技巧（改稿时逐条用）

- **长短句穿插**：一句长叙事 + 两句短动作/短状态，自带呼吸感。铺垫用长句，高潮换短句——长句拉弓，短句放箭。删「的、了、着」。
- **画面感**：模糊词换成具体画面（颜色、材质、形状）；镜头按远景→中景→特写推进；每场景至少调用两种感官（触觉、嗅觉最易被忽略，也最有代入感）。
- **对话**：每段对话带目的（交锋、试探、信息差），删纯寒暄；信息放在冲突里投放，不用旁白讲课。
- **校对底线**：错字连篇、语句不通直接劝退。发布前至少自查一遍错字与标点。

## 审查要点

- 本章是否只有一个核心事件？多余支线是否可砍？
- 开头 200 字内是否已进入状态，无寒暄式开头？
- 章末钩子属于哪种类型？是否停在最痒处？
- 通读一遍：有无连续 5 句以上的同长度句式？有无形容词堆砌而无具体画面？
