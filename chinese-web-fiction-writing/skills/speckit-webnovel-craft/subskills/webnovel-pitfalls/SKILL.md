# 网文新人十大死法与避坑诊断

## 十大死法对照表

| # | 死法 | 解法 |
|---|---|---|
| 1 | 闭门造车，不看市场直接开写，莽 50 万字 | 先扫榜再开书；2–5 万字即寻求签约反馈，及时止损 |
| 2 | 书名随意、简介敷衍 | 门面工程投入不低于写三章正文（见 webnovel-packaging） |
| 3 | 开篇写序章楔子、大段背景设定 | 删掉，第一句就进冲突（见 webnovel-opening） |
| 4 | 第一人称「我」 | 改第三人称，给主角起名字 |
| 5 | 无大纲，想到哪写到哪，剧情跑偏拉不回 | 至少做简纲：主线一句话 + 滚动细纲；支线服务主线 |
| 6 | 快切快开，频繁换题材开新坑 | 耐住性子；成绩差也写到 30–50 万字再切，锻炼中后期能力 |
| 7 | 扫榜乱融梗，缝成四不像 | 先定目标读者，融梗服务核心卖点，不是堆料 |
| 8 | 金手指过强/设定前后矛盾 | 功能 ≤3、有代价；建设定规则清单逐卷对照 |
| 9 | 更新不稳定、随意断更 | 固定时间日更 4000+，存稿兜底；断更是数据和福利的双重死刑 |
| 10 | 开局自嗨、拒绝反馈、四处打广告 | 数据与评论是唯一裁判；书好自然有量，广告救不了烂书 |

## 心态红线

第一本书不火是常态。行业共识：写完一本完整作品（50–100 万字）才算出新手村，多数人在 40–100 万字后突然「怎么写怎么有」。把第一本当学费，把每一本当复利。

## 核心公式速查卡（诊断时对照）

```text
【核心梗】谁 + 处境 + 金手指/变数 + 要做什么
【简介】主角是谁 → 遇到什么 → 要干什么（+最大反差剧情）
【黄金三章】1 勾住(300字内出钩) → 2 加深(立核心矛盾) → 3 锁定(首个小高潮)
【爽点密度】3-5 章小爽点 / 10-15 章中高潮 / 30 章大反转 / 10 万字小高潮 / 20-30 万字大高潮
【剧情单元】铺垫(配角反应拉满) → 高潮(伏笔翻盘) → 收获(战利品+震惊) → 挂下一钩
【单章】1 个核心事件 + 章末钩子；开头 200 字内进状态
【升级】地图最高战力 = 主角等级 +1~2 阶；换地图必有前文铺垫
【金手指】功能 ≤3 + 有代价 + 可成长 + 新颖优先于强度
【更新】日更 4000+，固定时间，存稿 3-5 万字开书，断更 15 天 = 福利死刑
【签约节点】2/5/8 万字三次申请 → 8 万字开推荐 → 10 万字+连续 7 天更新冷启动
【复盘】找留存陡降点 → 归因(拖/堆/空窗/偏题) → 改文(算法实时有效)
```

## 诊断流程

1. 先定位死法：听用户描述症状（没签约/签约后没量/首秀跳水/追读掉），对照上表锁定 1–3 条最可能的死法。
2. 再下钻到对应专项 skill 处理：门面问题 → webnovel-packaging；开头问题 → webnovel-opening；节奏问题 → webnovel-pacing；结构问题 → webnovel-outline；人设问题 → webnovel-characters；单章问题 → webnovel-chapter。
3. 输出「死法 + 证据 + 具体改法」三段式结论，不空谈。
