# 网文爽点体系与节奏控制

长篇连载的核心引擎：**单位字数内的情绪回报率**。每日更新内容最好包含至少一个完整「压抑—释放」单元。

## 爽点类型库（混配 3–4 种，避免读者疲劳）

| 大类 | 具体爽点 |
|---|---|
| 实力类 | 打脸、越级反杀、人前显圣、扮猪吃虎、马甲掉落、无敌横推 |
| 成长类 | 升级突破、获得神功/神器、属性暴涨、资质逆天改命 |
| 财富类 | 暴富、捡漏、鉴宝、经营扩张、薅系统羊毛 |
| 地位类 | 身份揭露、大佬跪拜、众人震惊、权力晋升 |
| 情绪类 | 复仇雪恨、虐渣、沉冤得雪、护短、团圆 |
| 智力类 | 智斗破局、算计反派、信息差碾压、迪化流（配角脑补主角深不可测） |
| 感情类 | 苏点、暧昧拉扯、双向奔赴、吃醋、护妻/护夫 |

## 爽点密度公式

```text
每 1 章：      1 个核心事件 + 1 个章末钩子
每 3–5 章：    1 个小爽点
每 10–15 章：  1 个中高潮
每 30 章：     1 个大反转
每 10 万字：   1 个小高潮（阶段性大收获/大事件）
每 20–30 万字：1 个大高潮（卷级爆发，随后换地图/开新阶段）
```

铁律：爽点不集中堆砌（透支）、不长时间空缺（流失，空窗超 5 章即危险）。高潮过后给「收获 + 余韵」，再开下一轮铺垫。

## 糖葫芦串写法（剧情骨架）

每颗糖葫芦 = 一个完整爽点单元：

```text
铺垫（被轻视/危机逼近/配角反应烘托，情绪弹簧压到底）
→ 高潮（主角出手，用前文埋过的伏笔/能力翻盘）
→ 收获（战利品 + 地位变化 + 配角震惊反应）
→ 顺手挂出下一颗糖葫芦的钩子
```

配套「动作—反应」：**多写配角反应**。出手前写轻视嘲讽拉紧张力；出手中写旁观者从质疑到失语；出手后写大佬称赞——爽感的最后一公里由配角反应完成。

## 期待感六法（追更钩子系统）

1. **信息差**：读者知道真相、书中人不知道（马甲文、迪化流引擎）。
2. **扮猪吃虎**：提前暗示主角底牌，反派跳越高读者越期待打脸。
3. **误会/阴差阳错**：让读者抓心挠肝（感情线利器）。
4. **目标 + 倒计时**：明确 deadline（「三十天后全城毁灭」），万事自带紧迫感。
5. **悬念链**：一个悬念将解时埋下一个，永远不让读者无债一身轻。
6. **断章卡点**：停在最痒处——停在「见到敌人之后」而非之前；停在反转前一刻、身份将揭未揭时。

## 反转四招

1. **逻辑误导**：先给合理假象再揭真实动机，行为不变、动机全变。
2. **人设底色置换**：最不可能的人做最不可能的事；先立 A 面埋违和感，高潮揭 B 面。
3. **多重套娃**：假象→真相→真相是另一个假象的掩护；每层留消化空间，最终反转须解释前面所有不合理。
4. 铁律：**没有伏笔的反转叫炸糖，有伏笔的反转才是烟花**。维护伏笔清单文档，埋一条记一条，用完划掉。

## 高潮六招

多线汇聚同时引爆 / 极限压抑堵死退路 / 时间+自身+社会压力多重叠加 / 翻盘手段必是前文伏笔 / 侧面烘托围观者反应 / 打完留情绪余韵不急着收工。

## 诊断用法

留存在某处陡降时按序排查：节奏拖沓（删）→ 设定堆砌（后置）→ 爽点空窗超 5 章（补小高潮）→ 剧情偏离核心梗（纠偏）。
