# 网文门面工程（书名 / 简介 / 封面 / 章标）

读者找书路径：**书名 → 简介 → 评论区 → 目录章标 → 正文**。每一环都在筛掉读者，门面四件套投入的精力应不低于写三章正文。

## 书名

规则：4–15 字，**必须包含核心卖点或类型信号**。

三种高转化结构：
1. 身份反差型：《满宫不孕，唯我三年抱俩》《奸臣她不想当万人迷》
2. 设定直给型：《没钱修什么仙？》《游戏入侵：开局金刚明王功》
3. 流派+变数型：《封神：开局反出西岐，我死守渑池》

检验（1 秒测试）：只看书名，目标读者能否 1 秒判断「这是不是我的菜」？不能就改。

## 简介

三句话骨架：**主角是谁 → 遇到什么（核心冲突/变数）→ 要干什么（主线目标）**。

进阶四段式（女频/晋江尤其重要）：

```text
【一句话起因】xx 穿越/重生成 xx。
【金手指+任务】系统/变数要求他做什么，他的反应是什么。
【反差剧情】2-3 个最有张力的剧情片段或对话，展示最大反差。
【氛围收尾】一句符合文章调性的话（搞笑/阴森/热血）。
```

原则：**把最爽、最反常的东西放进简介，不要藏**。主线升级方向要在简介中可见。

## 封面

- 封面只需完成一个任务：与书名、简介调性一致，1 秒传递题材类型与氛围（男频重冲击力/女频重美感与 CP 感）。
- 审查时只问：目标读者刷到这张封面，会不会联想到自己想看的那类书？

## 章标（章节标题）

章标是读者点目录时的二次筛选，要有悬念感、信息量，禁止随手写「第 X 章 王家」。

三种好用章标：
- 剧透半个冲突：《摊牌了，我不是杂役》
- 抛数字：《一拳，三万斤》
- 留疑问：《他怎么敢？》

## 审查清单（产出或审稿时逐条过）

- [ ] 书名 4–15 字、含核心卖点、通过 1 秒测试
- [ ] 简介三句话骨架完整，含全书最大反差/最爽点
- [ ] 主线（升级方向）在简介中可见
- [ ] 封面与书名简介调性一致、类型信号清晰
- [ ] 抽查 10 个章标，个个有悬念/信息量，无流水账式命名
