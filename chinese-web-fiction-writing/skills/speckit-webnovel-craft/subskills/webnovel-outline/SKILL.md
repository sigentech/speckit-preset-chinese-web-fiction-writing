# 网文结构与大纲工程

## 三层大纲体系

| 层级 | 名称 | 内容 | 粒度 |
|---|---|---|---|
| L1 | 总纲（锚点） | 一句话核心梗、主题与故事承诺、开篇初始状态、结局最终状态、主角成长终点 | 1–2 页，钉死两端 |
| L2 | 卷纲（卷弧） | 卷目标（时间/地点/事件/主角收获）、核心冲突、开场与收尾状态、本卷大高潮 | 每卷 300–500 字 |
| L3 | 细纲（章纲） | 每章核心事件、冲突双方、爽点/钩子位置、出场人物 | 每章 50–150 字，滚动提前 5–10 章 |

实操原则：
- 签约前不做超大全纲（「大纲比正文多却签不了约」是浪费）：**主线一句话 + 前 5–6 万字细纲**即可。
- 连载期细纲滚动领先正文 5–10 章，防卡文又不锁死灵感。卡文 90% 是细纲断粮，先补细纲再写正文。
- 每卷结束自检：伏笔回收了吗？升级进度对吗？下卷地图和对手是谁？

## 大纲十步流程

1. 定题材（市场 × 擅长）→ 2. 定升级体系 → 3. 定主角性格 → 4. 用地图变化串主线（每地图 500 字概述）→ 5. 定主要配角与反派层级 → 6. 定开头与结局 → 7. 排卷级高潮位置 → 8. 列伏笔清单 → 9. 写前 5–6 万字细纲 → 10. 开写后可修订大纲，但不推翻锚点。

## 升级体系设计规则

- **前置完成**：开书前列完力量/职业/地位等级表（如炼气→筑基→金丹，或科员→科长→处长）。夺宝、打脸、发财全挂在这条线上。
- **规则清单化**：写下世界法则、能力上限、金手指「绝对不能做的事」，每卷对照检查——设定前后矛盾是读者弃书的硬理由。
- **地图匹配**：每张地图最高战力 ≈ 主角当前等级 +1~2 阶；换地图必须有前文铺垫的合理理由（追求意料之外、情理之中）。
- **速度控制**：用「地图容量」和「资源稀缺」两根阀门调节升级速度，既要快得爽，又不能快到崩盘。

## 卷纲模板

```text
第 X 卷：【卷名】
本卷目标：（主角要达成什么）
核心冲突：（对手是谁，矛盾是什么）
开场状态 / 收尾状态：（实力、地位、关系的变化）
关键事件：1. 2. 3.（每个事件对应 铺垫-高潮-收获）
本卷大高潮：第 X 章前后，引爆点是什么
新出场人物 / 退场人物：
埋下伏笔 / 回收伏笔：
```

## 审查要点

- 主线是否一句话说得清？所有支线是否服务主线？无关旁枝一律删减。
- 锚点（开头/结局状态）是否钉死？中间可以放开写，两端不许漂。
- 伏笔清单是否存在且持续维护？每条伏笔有埋有收。
