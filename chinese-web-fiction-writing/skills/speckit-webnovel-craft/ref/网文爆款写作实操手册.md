## 一、底层认知：先搞懂这门生意

### 1.1 网文的本质：连载式情绪商品

- 网络文学是一个年数百亿规模、覆盖 5 亿+用户的情绪消费市场。读者在地铁上、午休时、睡前十分钟打开你的书，不是来鉴赏文学的，而是来**快速获得情绪回报**的。
- 爆款网文的生产逻辑是一条「爽感流水线」：通过**「铺垫—压抑—爆发」**的情绪循环，把爽点批量化输出。每天更新的章节，最好都包含至少一个完整的「压抑—释放」情绪单元。
- 因此网文写作的第一性原理只有一句话：**单位字数内的情绪回报率**。一切技巧（黄金三章、爽点密度、断章钩子）都是这句话的推论。

### 1.2 读者留存曲线：你的书在哪里被判死刑

平台后台记录的读者行为数据呈现出极稳定的规律：

| 节点 | 典型留存（1 万次点击） | 含义 |
|---|---|---|
| 点开书 | 10000 | 书名/简介/封面决定 |
| 读完第 1 章 | ~5000 | 前 500–1000 字决定，过半弃书发生在第一章 1/3 处之前 |
| 读完第 3 章 | ~2000 | 黄金三章决定 |
| 读完第 10 章 | ~800 | 过完三章，弃书率大幅下降 |

**推论：**
- 开头几百字是你的全部筹码。读者不会给你时间，只会给你机会。
- 第 1 章负责「勾住」（产生兴趣），第 2 章负责「加深」（建立期待），第 3 章负责「锁定」（形成阅读惯性）。
- 书名、简介决定了有没有人点开；前三章决定了他留不留；后续每一章的章末钩子决定了他明天来不来。

### 1.3 算法时代的数据逻辑

- 番茄等免费平台：**算法推荐**。系统先圈一小批用户试投，根据留存、阅读时长、完读率决定是否扩量。**书是实时推荐的，你随时优化内容，算法随时调整给量**——这意味着改文永远有用，稳定更新永远是硬指标。
- 起点等付费平台：**编辑 + 读者数据双重筛选**（如四轮 PK / 流量包机制），同期新书同台竞技，谁的追读、收藏数据好，谁进下一轮推荐位。
- 两种生态的共同结论：**数据是写出来的，更是设计出来的**。你设计的每一个钩子、每一次爆发，最终都会变成后台曲线上的一个拐点。

## 二、平台选择与商业化路径

### 2.1 主流平台速选表

| 平台 | 模式 | 适合谁 | 关键规则 |
|---|---|---|---|
| 番茄小说 | 免费+广告分成 | 新人首选，算法给量相对公平 | 2万/5万/8万字各有 1 次签约申请机会；8万字可开推荐；10万字+连续 7 天稳定更新进入正式冷启动 |
| 起点中文网 | 付费订阅 | 有一定功底、想走精品 IP 路线 | 新书推荐 PK 制；全勤要求日更 4000 字；读者付费意愿高但要求也高 |
| 晋江文学城 | 付费订阅 | 女频、耽美、言情向作者 | 文案（简介）权重极高，读者社区文化强 |
| 飞卢小说网 | 付费 | 手速快、写脑洞同人流 | 节奏极快，书名简介决定生死，日更万字是常态 |
| 七猫/书旗等 | 免费 | 保底买断型作者 | 保底+分成，适合稳定量产 |
| 知乎盐选 | 短篇付费 | 短篇、脑洞故事 | 1–3 万字完结，反转密度极高 |

### 2.2 签约流程与关键节点（以番茄为例）

1. **实名认证**（手机号与身份证信息必须一致，否则签约失败）。
2. **发书 → 2 万字**：第 1 次签约申请机会。此后 5 万字、8 万字各 1 次，共 3 次。
3. **签约后 → 8 万字**：可主动点击「开始推荐」。
4. **10 万字 + 最近 7 天连续稳定更新**：推荐系统正式分发（冷启动/首秀），系统记录读者表现，决定后续给量。
5. **断更红线**：签约作品连续断更 15 天即被标记「断更」，失去全部福利（全勤奖、连载奖励等）。

### 2.3 收入结构认知

- **免费平台**：阅读/听书广告分成 + 全勤奖（如月更 15 万字+且月听读收益 ≥500 元，奖 600 元+分成；月更 20 万字档位更高）+ 星火计划（按 30/50/80/100 万字读完率发奖）+ 礼物 + 版权衍生（短剧、漫改是当下最大增量）。
- **付费平台**：订阅分成 + 全勤 + 月票/打赏 + IP 改编。
- **保底/买断**：千字 15–3000 元，适合有历史成绩的作者。
- **实操结论**：新人第一本书的合理目标是「签约 → 吃全勤 → 验证市场」，不要一开始就对标大神收入。

## 三、选题定位：开书前的生死决策

编辑们公认的新人第一大坑就是**闭门造车、盲目开书**：不考虑题材、风向、金手指，打开 Word 就是干，莽到四五十万字才发现没人看。选题阶段花 1–2 周，能把扑街概率降低一半以上。

### 3.1 扫榜：怎么扫、扫什么

**工具**：目标平台的畅销榜/新书榜、第三方情报站（如网文情报站、龙的天空论坛风向帖）。

**扫榜动作清单（每周固定 2–3 小时）：**
1. 看目标频道**新书榜前 50**：记录题材、书名结构、金手指类型。
2. 挑 3–5 本与自己想写方向最接近的**上升期书**（不是老神书，是近 3 个月起量的书），精读其：
   - 开篇前 3 章：怎么切入、主角怎么出场、第一段冲突是什么；
   - 书名与简介：卖点如何浓缩；
   - 前 10 万字的爽点排布：每隔几章一个小高潮。
3. 记录「赛道信号」：哪些分类在读均值在涨、新书占比高（供给少需求旺 = 机会窗口）。

### 3.2 选题评估：四问过滤法

开书前，用四个问题过滤你的创意：

1. **市场问**：这个题材当前在榜上有书跑通吗？（没有成功案例的方向，新人别碰；完全过时的方向也别碰，如传统异界大陆、都市异能、灵气复苏类已被编辑明确点名为「大概率不出成绩」。）
2. **能力问**：这个题材我读过 5 本以上代表作吗？我能写出它的「味道」吗？
3. **差异问**：我的书和榜上同类书相比，**一句话能讲清楚的不同点**是什么？（题材融合是最实用的微创新：如「修仙+资本逻辑」「无限流+规则怪谈」「宫斗+系统」。）
4. **续航问**：这个核心梗能支撑 100 万字吗？升级线清晰吗？

**编辑推荐的稳妥方向**（男频向，供参考）：都市文娱/职业文、重生流、玄幻系统流/属性流/武道长生、历史朝代文、游戏种田/LOL 职业文、体育（NBA/世界杯）属性系统文、传统仙侠、西游洪荒聊斋、诸天同人。**纯新人可从同人练笔切入**（自带世界观与读者，签约相对容易），小成后转原创。

### 3.3 提炼核心梗（一句话卖点）

把整本书压缩成一句话，格式：

> **【谁】+【在什么处境下】+【获得了什么特殊能力/变数】+【要做什么】**

例：「一个负债的杂役弟子，发现修仙界的一切都可以按揭分期，于是用金融手段一路算计成大佬。」

检验标准：
- 这句话里必须有**反差或冲突**；
- 能直接推导出前 10 章剧情；
- 能原样改写成简介的第一句。

## 四、门面工程：书名、简介、封面、章标

读者找书的路径是：**书名 → 简介 → 评论区 → 目录章标 → 正文**。前四个环节每一环都在筛掉人。

### 4.1 书名公式

- **必须包含核心卖点或类型信号**，4–15 字为宜。
- 常用结构：
  - 身份反差型：《满宫不孕，唯我三年抱俩》《奸臣她不想当万人迷》
  - 设定直给型：《没钱修什么仙？》《游戏入侵：开局金刚明王功》
  - 流派+变数型：《封神：开局反出西岐，我死守渑池》
- 自检：只看书名，目标读者能否 1 秒判断「这是不是我的菜」？不能就改。

### 4.2 简介公式

**三句话骨架**：主角是谁 → 遇到什么（核心冲突/变数）→ 要干什么（主线目标）。

进阶写法（女频/晋江尤其重要）：

```
【一句话起因】xx 穿越/重生成 xx。
【金手指+任务】系统/变数要求他做什么，他的反应是什么。
【反差剧情】2-3 个最有张力的剧情片段或对话，展示最大反差。
【氛围收尾】一句符合文章调性的话（搞笑/阴森/热血）。
```

原则：**把最爽、最反常的东西放在简介里，不要藏**。

### 4.3 章标

- 章标是读者点目录时的二次筛选，要有悬念感、信息量，不要随手写「第 X 章 王家」。
- 好用的章标：剧透半个冲突（《摊牌了，我不是杂役》）、抛数字（《一拳，三万斤》）、留疑问（《他怎么敢？》）。

## 五、黄金三章：开篇工程

### 5.1 总原则：简单 + 有趣

好开篇只有两条标准——**简单**和**有趣**（阅文起点创作学堂）。

**做到「简单」的三刀：**
1. **砍无关内容**：开局每一段都问「删了它，故事还成立吗？」成立就删。
2. **砍特殊信息量**：人名、地名、功法名、势力名都是读者要花脑子记的东西。前三章出场人物越少越好，非必要的一个不出场。
3. **后置必要的无聊内容**：背景、设定、主角前史，能挪到三章之后边讲故事边交代的，一律后置。

### 5.2 三章任务分解表

| 章节 | 任务 | 具体操作 |
|---|---|---|
| 第 1 章 | 勾住 | **前 300 字内必须出现钩子**（悬念、冲突、金手指亮相，三选一）；主角在前半章出场，亮明身份和当下困境；章末留钩 |
| 第 2 章 | 加深 | 核心矛盾确立，读者要知道「这本书讲什么」；金手指用法展示；引出长期冲突（主角不得不做的事） |
| 第 3 章 | 锁定 | 第一个小高潮，明确爽点类型，让读者确认「这书对我胃口」；铺垫不超过 500 字 |

附加要求：打斗文/升级文前五章内**亮出力量体系**；每章章末留钩。

### 5.3 开篇五法（可直接套用）

1. **不通的画面**：抛出一件说不通的事，先不解释（解释是悬念的天敌）。
2. **反差**：身份与行为错位，反差越大越好（乞丐讲金融、圣子去摆摊）。
3. **跳过铺垫，第一句就进冲突**：干架、退婚、处死、分手、被抓。
4. **平静地说荒诞**：用习以为常的语气亮出世界观（「灵根分期付款」）。
5. **血压开局**：写不公，而不是写惨——付出与回报的落差越大，读者越想让主角赢。

核心就一个字：**打破**（打破日常、打破预期、打破平衡）。

### 5.4 开篇禁忌清单（新人高频死因）

- ❌ 写序章/楔子（直接上正文第一章）
- ❌ 第一人称「我」（用主角名字，第三人称）
- ❌ 大段环境描写、背景介绍、抒情开头
- ❌ 前三章抛出大量设定、人名、势力关系
- ❌ 开局慢悠悠的日常（「先让读者熟悉一下世界」= 让读者离开）
- ❌ 主角到第三章还没出场或没有欲望目标

### 5.5 黄金三章自检表（写完逐条打勾）

- [ ] 前 300 字有钩子（悬念/冲突/金手指）
- [ ] 第一章前 1/3 处主角已出场，有名字、有身份
- [ ] 三章内主角有明确的短期目标+长期冲突
- [ ] 出场人物 ≤ 5 个，且每个都有戏份必要性
- [ ] 专有名词 ≤ 5 个
- [ ] 金手指（若有）已亮相并展示过一次用法
- [ ] 每章章末有钩子
- [ ] 第三章出现了一个小爽点
- [ ] 通篇无大段背景/环境/前史介绍
- [ ] 删掉任何一段，故事都会受影响（否则该段就是废话）

## 六、爽点体系与节奏控制

这是长篇连载的核心引擎，建议打印贴在写作区。

### 6.1 爽点类型库（按题材取用）

| 大类 | 具体爽点 |
|---|---|
| 实力类 | 打脸、越级反杀、人前显圣、扮猪吃虎、马甲掉落、无敌横推 |
| 成长类 | 升级突破、获得神功/神器、属性暴涨、资质逆天改命 |
| 财富类 | 暴富、捡漏、鉴宝、经营扩张、薅系统羊毛 |
| 地位类 | 身份揭露、大佬跪拜、众人震惊、权力晋升 |
| 情绪类 | 复仇雪恨、虐渣、沉冤得雪、护短、团圆 |
| 智力类 | 智斗破局、算计反派、信息差碾压、迪化流（配角脑补主角深不可测） |
| 感情类 | 苏点、暧昧拉扯、双向奔赴、吃醋、护妻/护夫 |

**要点**：不要只用一种爽点。根据题材与人设混配 3–4 种，避免读者疲劳。

### 6.2 爽点密度公式（行业通用节奏）

```
每 1 章：     1 个核心事件 + 1 个章末钩子
每 3–5 章：   1 个小爽点
每 10–15 章： 1 个中高潮
每 30 章：    1 个大反转
每 10 万字：  1 个小高潮（阶段性大收获/大事件）
每 20–30 万字：1 个大高潮（卷级爆发，随后换地图/开新阶段）
```

**铁律**：每天更新的内容里最好包含一个完整的「压抑—释放」单元；爽点既不能集中堆砌（透支），也不能长时间空缺（流失）。高潮过后要给「收获+余韵」，再开启下一轮铺垫。

### 6.3 糖葫芦串写法（编辑推荐的剧情骨架）

把全书看成一串糖葫芦，**每一颗糖葫芦 = 一个完整的爽点单元**，结构为：

```
铺垫（被轻视/危机逼近/配角反应烘托，把情绪弹簧压到底）
  → 高潮（主角出手，用前文埋过的伏笔/能力翻盘）
  → 收获（战利品+地位变化+配角震惊反应）
  → 顺手挂出下一颗糖葫芦的钩子
```

配套技巧「动作—反应」：**多写配角的反应**。主角出手前，写配角的轻视与嘲讽来拉紧张力；出手中，写旁观者从质疑到失语；出手后，写大佬级角色的称赞——爽感的最后一公里是由配角的反应完成的。

### 6.4 期待感六法（让读者追更的钩子系统）

1. **信息差**：读者知道真相、书中人不知道（马甲文、迪化流的核心引擎）。
2. **扮猪吃虎**：提前向读者暗示主角的底牌，反派跳得越高，读者越期待打脸。
3. **误会/阴差阳错**：让读者抓心挠肝地想看清真相（感情线利器）。
4. **目标+倒计时**：给主角一个明确 deadline（「三十天后全城毁灭」），所有剧情获得天然的紧迫感。
5. **悬念链**：一个悬念快解开时，提前埋下下一个，永远不让读者「无债一身轻」。
6. **断章卡点**：章末停在最痒处——停在「见到敌人之后」而不是「见到敌人之前」；停在反转前一刻、身份将揭未揭时。

### 6.5 反转四招

1. **逻辑误导**：先给合理假象，再揭真实动机——行为不变，动机全变。
2. **人设底色置换**：最不可能的人做最不可能的事；先立 A 面，在温情里埋违和感，高潮揭 B 面。
3. **多重套娃**：假象→真相→真相是另一个假象的掩护；每层留消化空间，最终反转要能解释前面所有不合理。
4. **铁律**：没有伏笔的反转叫炸糖，有伏笔的反转才是烟花。**建立伏笔清单文档**，埋一条记一条，用完划掉。

### 6.6 高潮六招

多线汇聚同时引爆 / 极限压抑堵死退路 / 时间压力+自身限制+社会压力多重叠加 / 翻盘手段必是前文伏笔 / 侧面烘托围观者反应 / 打完留情绪余韵不急着收工。

## 七、结构与大纲工程

### 7.1 三层大纲体系

| 层级 | 名称 | 内容 | 粒度 |
|---|---|---|---|
| L1 | 总纲（锚点） | 一句话核心梗、主题与故事承诺、开篇初始状态、结局最终状态、主角成长终点 | 1–2 页，钉死两端 |
| L2 | 卷纲（卷弧） | 每卷：卷目标（时间/地点/事件/主角收获）、核心冲突、开场与收尾状态、本卷大高潮 | 每卷 300–500 字 |
| L3 | 细纲（章纲） | 每章：核心事件、冲突双方、爽点/钩子位置、出场人物 | 每章 50–150 字，**滚动提前 5–10 章** |

**实操原则**：
- 新人不必做几十万字的超大全纲——「大纲比正文多却签约不了」是编辑点名的常见浪费。**签约前做简纲即可：主线一句话 + 前 5–6 万字细纲**。
- 连载期保持「细纲滚动领先正文 5–10 章」，既防卡文，又不锁死灵感。
- 每卷结束开半天会（和自己）：本卷伏笔回收了吗？升级线进度对吗？下卷地图和对手是谁？

### 7.2 大纲十步精简流程

1. 定题材（结合市场与擅长）→ 2. 定升级体系（能细则细，它是一切 YY 点的基础）→ 3. 定主角性格 → 4. 用「地图变化」串主线情节（每个地图 500 字概述）→ 5. 定主要配角与反派层级 → 6. 定开头与结局 → 7. 排卷级高潮位置 → 8. 列伏笔清单 → 9. 写前 5–6 万字细纲 → 10. 开写后允许修订大纲，但不推翻锚点。

### 7.3 升级体系设计规则

- **前置完成**：开书前把力量/职业/地位等级表列完（如炼气→筑基→金丹…或科员→科长→处长…）。金手指、夺宝、打脸全部挂在这条线上。
- **规则清单化**：写下世界法则、能力上限、金手指「绝对不能做的事」。写每卷前对照检查，避免前后矛盾（设定前后不一致是读者弃书的硬理由）。
- **地图匹配**：每张地图的最高战力 ≈ 主角当前等级+1~2 阶，保证「这张图上确实没几人能威胁他」；换地图必须有前文铺垫的合理理由。
- **速度控制**：主角升级既要快得爽，又不能快到崩盘——用「地图容量」和「资源稀缺」两根阀门调节。

### 7.4 卷纲模板

```
第 X 卷：【卷名】
本卷目标：（主角要达成什么）
核心冲突：（对手是谁，矛盾是什么）
开场状态 / 收尾状态：（实力、地位、关系的变化）
关键事件：1. 2. 3.（每个事件对应铺垫-高潮-收获）
本卷大高潮：第 X 章前后，引爆点是什么
新出场人物 / 退场人物：
埋下伏笔 / 回收伏笔：
```

## 八、人物系统

### 8.1 主角设计：三个锚点

1. **身份/职业**：穿越后主角必须立刻有一个身份（捕快、小侯爷、演员、杂役……）。身份是剧情的发生器——没有身份，就没有具体的事可发生，只能写出「路边唱歌路人喊牛逼」这种空桥段。
2. **欲望/目标**：短期目标（活下去/还债/复仇）+ 长期主线（一步步成名/升级/查明真相）。**这条升级主线要直接写进简介**。
3. **金手指**：设计规则——核心功能 ≤3 个；有明确限制或代价；初始弱、可成长；**新颖性 > 强度**（挂太强求易写崩成流水账，挂有趣才能出记忆点）。

### 8.2 代入感配方

- 主角起点尽量贴近目标读者（普通人、社畜、学生），遭遇的不公要具体到细节；
- 写「不公」而非「卖惨」：付出与回报的落差才是读者情绪的燃料；
- 给主角「做不到但必须做」的两难，写纠结的过程，不只写结果。

### 8.3 反派设计：三种类型 × 层级递进

- **棋手型**：步步算计、借刀杀人、留一个没算到的变量（用于中后期大 boss）。
- **殉道者型**：目的高尚、手段残忍，信念比主角更纯粹，让读者「停下来想一想」。
- **影子型**：藏在主角身边，前期越可靠越好，每件好事背后埋伏笔，揭穿时颠覆主角认知。

**铁律**：永远不要为了衬托主角而削弱反派。反派越强，胜利越有含金量。反派按「小混混 → 地方势力 → 宗门/集团 → 世界级对手」层级递进，与地图和升级线同步扩容。

### 8.4 配角工具箱

- 每个重要配角给一句「反应模式」设定（见到主角就脑补/就抬杠/就护短），配角的功能 80% 是通过**反应**来完成的；
- 重要配角也要有「想要但得不到」的东西，否则就是工具人；
- 写死亡/离别前，先写足够多的日常互动细节——想让读者哭，先让读者爱上这个角色。

## 九、章节微操：文笔与单章结构

### 9.1 单章内部结构（2000–3000 字/章）

```
开头（≤200 字）：快速进入状态，承接上章钩子，不寒暄
中段：推进 1 个核心事件（一章只讲一件事，干干净净）
收尾：停在悬念/反转/危机将爆处
```

### 9.2 章末钩子的常用类型

新危机降临 / 反转前一刻 / 身份将揭未揭 / 强者登场 / 主角做出反常决定 / 获得关键信息但来不及行动。**写完每章自查：这一章停在这儿，我自己想不想点下一章？**

### 9.3 可读性技巧（立刻能用）

- **长短句穿插**：一句长叙事 + 两句短动作/短状态，自带呼吸感；铺垫用长句，高潮换短句——长句拉弓，短句放箭；删「的、了、着」。
- **画面感**：把模糊词换成具体画面（颜色、材质、形状）；镜头按远景→中景→特写推进；至少调用两种感官（触觉、嗅觉最容易被忽略，也最有代入感）。
- **对话**：对话要带目的（交锋、试探、信息差），删掉纯寒暄；信息放在冲突里投放，不用旁白讲课。
- **校对底线**：错字连篇、语句不通会直接劝退。发布后至少自查一遍错字与标点。

## 十、连载运营与数据复盘

### 10.1 更新策略

| 项目 | 建议 |
|---|---|
| 日更字数 | 底线 4000 字（多数平台全勤线），理想 6000+；分两更（如 12 点、20 点）比一更曝光更稳 |
| 更新时间 | 固定时间发布，培养读者追更习惯，也降低「太监」预期 |
| 存稿 | 开书前存 3–5 万字为宜；**切勿存稿十几万字却还没签约**（签不了约全成废稿） |
| 爆更 | 留给关键节点：首秀/上推荐位期间、大高潮剧情期间、冲榜期 |
| 请假 | 避免断更；番茄签约作品连续断更 15 天即失去全部福利 |

### 10.2 签约前后关键节点动作

```
2 万字   → 第 1 次签约申请（不过则改，5 万字第 2 次，8 万字第 3 次）
           ※ 起点系：正常 1–3 万字内编辑会审核，5 万字无站短可后台申签；
             超过仍无动静 → 果断调整开头或准备下一本，不要头铁莽到 50 万字
签约后  → 保持稳定更新，打磨书名简介封面
8 万字  → 主动开启推荐
10 万字 → 冷启动/首秀：此前务必攒出「7 天连续稳定更新」，首秀期是流量放大器，
           可适当爆更，密切盯数据
首秀后  → 进入数据复盘循环（见下）
```

### 10.3 数据复盘 SOP（每周一次）

1. **看曲线**：找到留存陡降的章节位置——那就是弃书点。
2. **归因**：弃书点处通常是：节奏拖沓（删）、设定堆砌（后置）、爽点空窗超过 5 章（补小高潮）、剧情转向与核心梗不符（纠偏）。
3. **对症改文**：算法平台改文实时有效，数据转好算法会重新给量，**永远值得回头修**。
4. **看评论区**：读者吐槽集中在哪（毒点）、夸奖集中在哪（爽点）——毒点速改，爽点加量。多与读者互动，但不被个别意见带偏主线。
5. **核对大纲**：升级进度是否过快/过慢？伏笔是否有烂尾风险？

### 10.4 卡文应对

- 卡文 90% 是**细纲断粮**：回头把后续 5–10 章细纲补上，比硬憋正文有效；
- 写得慢：给每次写作定具体目标（「这 90 分钟写完这场冲突」），换环境、关后台数据页；
- 真写不动：跳写本章高潮段落，再倒填铺垫；或砍剧情——问自己「这段剧情删了主线断不断」，不断就删。

## 十一、新人十大死法与避坑清单

| # | 死法 | 解法 |
|---|---|---|
| 1 | 闭门造车，不看市场直接开写，莽 50 万字 | 先扫榜再开书；2–5 万字即寻求签约反馈，及时止损 |
| 2 | 书名随意、简介敷衍 | 门面工程花的时间应不低于写三章正文 |
| 3 | 开篇写序章楔子、大段背景设定 | 删掉，第一句就进冲突 |
| 4 | 第一人称「我」 | 改第三人称，给主角起名字 |
| 5 | 无大纲，想到哪写到哪，剧情跑偏拉不回 | 至少做简纲：主线一句话+滚动细纲；一切支线服务主线 |
| 6 | 快切快开，频繁换题材开新坑 | 耐住性子写完一本；成绩差也写到 30–50 万字再切，锻炼中后期能力 |
| 7 | 扫榜乱融梗，缝成四不像 | 先弄清目标读者是谁，融梗服务于核心卖点，不是堆料 |
| 8 | 金手指过强/设定前后矛盾 | 功能≤3、有代价；建立设定规则清单逐卷对照 |
| 9 | 更新不稳定、随意断更 | 固定时间日更 4000+，存稿兜底；断更是数据和福利的双重死刑 |
| 10 | 开局自嗨、拒绝反馈、四处打广告 | 数据与评论是唯一裁判；书好自然有量，广告救不了烂书 |

另加一条心态红线：**第一本书不火是常态**。行业共识是——写完一本完整作品（50–100 万字）的人才算出了新手村；多数人是在 40–100 万字之后突然「怎么写怎么有」。把第一本当学费，把每一本当复利。

## 十二、落地执行系统：清单、SOP 与 30 天计划

### 12.1 开书前检查清单（全部打勾才允许发书）

**选题**
- [ ] 已扫目标频道新书榜，记录 ≥10 本上升期同类书
- [ ] 精读 3 本对标书的前 3 章与前 10 万字爽点排布
- [ ] 核心梗一句话已写出，含反差/冲突，能推导前 10 章
- [ ] 题材在榜上有近 3 个月的成功案例

**设定**
- [ ] 升级体系表完成（等级、每级标志、资源消耗）
- [ ] 金手指规则完成（功能≤3、限制、成长路径）
- [ ] 世界观规则清单完成（只写「够用」的部分，其余随写随补）
- [ ] 主角三锚点完成（身份、欲望、性格一句话）
- [ ] 主要反派层级表完成（至少前两个层级）

**结构**
- [ ] 总纲锚点：开头状态、结局状态、主线一句话
- [ ] 第 1 卷卷纲完成
- [ ] 前 5–6 万字细纲完成
- [ ] 伏笔清单文档已建立

**门面与开篇**
- [ ] 书名含核心卖点，通过 1 秒测试
- [ ] 简介按三句话公式完成
- [ ] 前 3 章通过第五章自检表全部条款
- [ ] 存稿 3–5 万字

### 12.2 每日写作 SOP

1. 写作前 10 分钟：过一遍今日要写章节的细纲，明确本章「核心事件+章末钩子」。
2. 写作 2–4 小时：完成当日更新量（4000–6000 字），先写完再改，不边写边删。
3. 修改 20 分钟：查错字、删「的了着」、检查章末钩子。
4. 定时发布；顺手存 1 章应急稿（存稿池水位低于 3 章时拉警报）。
5. 每周日：数据复盘（10.3）+ 补后续 5–10 章细纲 + 扫榜 1 小时。

### 12.3 30 天从 0 到开书计划

| 阶段 | 天数 | 任务 |
|---|---|---|
| 市场调研 | D1–D7 | 选平台与频道；扫榜；精读 3 本对标书；写下核心梗一句话 |
| 设定搭建 | D8–D12 | 升级体系、金手指、主角三锚点、反派层级、总纲锚点 |
| 结构与细纲 | D13–D17 | 第 1 卷卷纲 + 前 5–6 万字细纲 + 伏笔清单 |
| 门面与开篇 | D18–D23 | 书名/简介/封面方向；写前 3 章并对照自检表改 2 轮 |
| 存稿冲刺 | D24–D29 | 日更 4000+ 攒存稿至 3–5 万字；同时完善第 2 卷卷纲 |
| 发书 | D30 | 检查 12.1 全部清单 → 发布 → 固定更新时间 |

### 12.4 常用信息源

- 官方教学：番茄作家专区「作家课堂」、阅文作家助手「起点创作学堂」、各平台编辑「开放日」答疑帖
- 风向情报：龙的天空论坛、第三方榜单情报站（赛道在读均值、新书占比、涨跌信号）
- 同行交流：作家助手社区话题、晋江碧水论坛经验帖

## 附录：核心公式速查卡

```
【核心梗】谁 + 处境 + 金手指/变数 + 要做什么
【简介】主角是谁 → 遇到什么 → 要干什么（+最大反差剧情）
【黄金三章】1 勾住(300字内出钩) → 2 加深(立核心矛盾) → 3 锁定(首个小高潮)
【爽点密度】3-5 章小爽点 / 10-15 章中高潮 / 30 章大反转 / 10 万字小高潮 / 20-30 万字大高潮
【剧情单元】铺垫(配角反应拉满) → 高潮(伏笔翻盘) → 收获(战利品+震惊) → 挂下一钩
【单章】1 个核心事件 + 章末钩子；开头 200 字内进状态
【升级】地图最高战力 = 主角等级 +1~2 阶；换地图必有前文铺垫
【金手指】功能 ≤3 + 有代价 + 可成长 + 新颖优先于强度
【更新】日更 4000+，固定时间，存稿 3-5 万字开书，断更 15 天 = 福利死刑
【签约节点】2/5/8 万字三次申请 → 8 万字开推荐 → 10 万字+连续 7 天更新冷启动
【复盘】找留存陡降点 → 归因(拖/堆/空窗/偏题) → 改文(算法实时有效)
```
