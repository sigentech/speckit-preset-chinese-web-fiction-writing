# speckit-preset-chinese-web-fiction-writing

中文长篇网文的 [Spec Kit](https://github.com/github/spec-kit) 预设：完整小说工作流 + 网文商业写法技能树（门面工程、黄金三章、爽点节奏、三层大纲/升级体系、人物系统、章节微操、十大死法诊断）。

A Spec Kit preset for Chinese serialized web fiction — the full fiction-book-writing workflow plus a webnovel craft skill tree.

## Contents

```
chinese-web-fiction-writing/   ← 可被 specify preset add 一键安装的预设目录
```

## Installation

```bash
specify preset add --from https://github.com/sigentech/speckit-preset-chinese-web-fiction-writing/releases/download/v1.0.0/chinese-web-fiction-writing.zip
```

本地开发：`specify preset add --dev /path/to/this-repo/chinese-web-fiction-writing`
